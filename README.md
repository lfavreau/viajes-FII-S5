# Agencia de viajes

Aplicación React para consultar destinos, vuelos y hoteles con datos simulados.

- REST y MSW: listado de destinos, países y actividades.
- GraphQL, Apollo y MSW: vuelos y hoteles por destino, con precios, fechas y disponibilidad.
- React Router: navegación entre vistas.

Para ejecutar: `npm install` y `npm start`.
